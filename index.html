01. 실험실 망 분리와 랜섬웨어 사고 대응

에이프로젠제약 · 네트워크 설계 / 사고 대응

시험 데이터의 중요도를 기준으로 경계를 설계하고, 실제 사고에서 보호 효과를 확인했습니다.

상황과 판단

  • 실험실 분석 장비와 시험 데이터가 일반 업무망과 같은 대역에 존재
  • 데이터 손실 시 품질·시험 근거에 미칠 영향을 고려해 별도 구간 분리 추진

직접 수행

  • VLAN·IP 대역을 분리하고 Secui Bluemax로 업무상 필요한 통신만 허용
  • 현업 업무 흐름을 확인해 대체 접속 경로와 예외 승인 절차 마련
  • 감염 장비 식별·격리, 로그 확인, 백업 상태 점검 및 복구 대응

후속 개선

  • 불필요한 원격 접근을 정리하고 방화벽 정책 재점검
  • Veeam 기반 백업 체계를 도입하고 복구 절차 정비
  • 초동 대응·격리·복구·재발 방지 흐름 문서화
실제 랜섬웨어 사고에서 분리된 실험실 시험 데이터 유실 0건. 보호 대상의 중요도를 네트워크 정책에 반영했습니다.

02. 스팸필터 장애, 메일 수신 복구와 정상 경로 원복

현진스포텍 · Wblock / DNS / SMTP

메일 흐름을 구간별로 추적해 장애 장비를 우회하고, 교체 후 정상 구조까지 복구했습니다.

상황과 진단

  • Wblock 장비 장애로 외부 메일 수신 중단
  • DNS MX → 방화벽 → 스팸필터 → 메일 서버의 흐름을 점검해 장애 구간 분리

임시 복구

  • MX 레코드와 필요한 방화벽 정책을 변경해 메일 서버 직접 수신으로 전환
  • 외부 메일 서비스에서 테스트 발송하여 수신 상태와 DNS 반영 확인

장비 교체와 검증

  • 유지보수 업체와 하드웨어 교체·기존 설정 복원 진행
  • MX와 스팸필터 경로 원복 후 메일 송수신 최종 점검
  • 임시 변경과 원복 내역을 장애 기록으로 정리
임시 우회 복구 → 장비 교체 → 정상 경로 원복까지 수행해 메일 수신을 정상화했습니다.
